## Структура проекта

```text
RTC-championship/
└── dataset_case3_v1.0_fix/
    ├── app.py                  # Веб-приложение на Streamlit
    ├── index.py                # Парсинг кода, генерация эмбеддингов и сохранение в ChromaDB
    ├── llm.py                  # Модуль взаимодействия с LLM (функции чата)
    ├── score.py                # Скрипт валидации и подсчёта метрики Precision@5
    ├── requirements.txt        # Список зависимостей Python
    ├── .dockerignore           # Исключения для сборки Docker
    ├── Dockerfile              # Инструкция сборки Docker-образа
    ├── docker-compose.yml      # Конфигурация Docker Compose
    └── sample_queries.txt      # Примеры поисковых запросов
```
# Инструкция запуска

## Первый вариант 
Переход в рабочую директорию и запуск индексирования:
```bash
cd dataset_case3_v1.0_fix 
python index.py gymhero qrcode-generator-master
```
Запуск веб-интерфейса
```bash
streamlit run app.py
```
Оценка качества (подсчёт метрики)
```bash
python score.py --predictions results.json --questions eval_questions.json
```
## Второй вариант
Запуск в Docker-контейнере
```bash
docker compose up --build
```
## Подробнее об архитектуре
1. Запуск index.py, который на вход принимает две директории - для Python и Java исходного кода. ->
Сначала создание коллекции ChromaDB -> скрипт разбивает Python код с помощью модуля ast чанки,
потом также Java код, но с модулем tree-sitter(чанки - это функции и классы) -> перевод чанков в
эмбеддинги -> сохранение чанков и эмбеддингов БД
2. Запуск app.py -> создание интерфейса -> подключение к БД ->
a. Запрос для поиска фрагментов вопроса -> Получение из БД пяти наиболее релевантных фрагментов кода
b. Вопрос к LLM -> Вывод пояснения - get_llm_explanation функция из llm.py

# Требования к прототипу

## Обязательные

1. ✅Индексирующий скрипт корректно режет файлы на функции и классы, сохраняет эмбеддинги в ChromaDB (или FAISS).
2. ✅Семантический поиск возвращает релевантные фрагменты по запросу на русском или английском. 
3. ✅Веб-интерфейс на Streamlit показывает результаты с подсветкой синтаксиса и оценкой релевантности. 
4. ✅Система запускается двумя командами: python index.py <папка> для индексирования и streamlit run app.py для UI. 
5. ✅README содержит описание архитектуры, инструкцию запуска, 5 примеров запросов с ответами и обоснование стратегии чункования.

## Дополнительные 

1. ✅LLM-ответы: чат-режим с генерацией связного ответа на основе найденных фрагментов. 
2. ❌Гибридный поиск: комбинация векторного и полнотекстового с настраиваемым весом. 
3. ❌Метрики качества: Precision@5 вычисляется и показывается на отдельной странице Streamlit. 
4. ✅Поддержка второго языка (Java или JavaScript) через tree-sitter или регулярки. 
5. ✅Docker Compose для запуска: docker compose up и всё работает.
